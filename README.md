# Tra cứu MRI tim theo bệnh

Web tĩnh (HTML/CSS/JS, không cần cài đặt) để chọn protocol MRI tim theo bệnh và tra cứu lâm sàng, hình ảnh, tiêu chuẩn chẩn đoán, chẩn đoán phân biệt. Dùng nội bộ.

- Mở: bấm đúp `index.html`.
- Hướng dẫn sử dụng và câu yêu cầu mẫu: `HUONG-DAN.md`.
- Quy tắc cho Claude Code: `CLAUDE.md`.
- Nguồn: CMR Pocket Guide 2nd ed. (EACVI 2017) và The EACVI Textbook of Cardiovascular Magnetic Resonance (2018).
